# 第十四章：别创业，先完成第一次交易

很多人一想到“自己赚钱”，脑中马上出现：

- 注册公司；
- 做品牌；
- 做网站；
- 做 App；
- 买域名；
- 起名字；
- 设计 Logo。

这些事情很像创业，所以会产生强烈的进展感。

但它们都可以在没有一个客户的情况下完成。

真正重要的里程碑只有一个：

> **有没有一个非雇主的人，因为你创造的价值，自愿把钱付给你。**

这就是“第一笔新钱”。

## 为什么第一笔钱比第一家公司重要

工资的交易结构已经由组织替你搭好：

- 公司找到客户；
- 公司定义岗位；
- 公司组织协作；
- 公司承担销售；
- 你完成其中一段工作。

自己赚钱时，这些保护层突然消失。

你必须第一次完整面对：

~~~text
找人
→ 理解问题
→ 提方案
→ 建立信任
→ 报价
→ 被拒绝
→ 成交
→ 交付
→ 收钱
~~~

哪怕最后只赚 300 元，这条链路也比“做了三个月产品但没人付钱”更有训练价值。

## 第一笔钱应该怎么选

你的目标不是利润最大化。

而是：

> **尽快完成一次真实闭环。**

所以第一笔交易最好满足：

- 问题具体；
- 客户可接触；
- 你已经有一定能力；
- 交付周期短；
- 风险可控；
- 能明确验收。

不要从“我要创造一个伟大产品”开始。

可以从：

> 我能不能帮一个具体的人，把一个具体问题解决掉？

开始。

## 服务为什么适合小白练习

软件和内容可以规模化，但早期很容易躲在产品背后，长期不和客户接触。

服务的好处是逼迫你：

- 找客户；
- 听需求；
- 报价；
- 交付；
- 处理变化。

它不一定是你的最终商业模式，但非常适合学习交易。

## 不要免费太久

免费可以用来换：

- 真实反馈；
- 案例；
- 数据；
- 进入场景的机会。

但如果永远免费，你永远验证不了：

> **别人到底愿不愿意为它付钱。**

“觉得不错”和“愿意付款”是两个完全不同的信号。

**师傅留的作业：设计你的第一笔新钱**

写下一项你在 7～14 天内能够交付的具体服务。

必须回答：

1. 卖给谁？
2. 解决什么问题？
3. 做完有什么结果？
4. 你准备收多少钱？
5. 去哪里找到第一个人？
6. 最迟哪一天提出第一次真实报价？

不要写“准备好了再开始”。

交易能力只能在交易里学。
