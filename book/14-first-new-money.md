# 第十四章：别创业，先完成第一次交易

很多人一想到“自己赚钱”，脑中马上出现：

- 注册公司；
- 做品牌；
- 做网站；
- 做 App；
- 买域名；
- 起名字；
- 设计 Logo。

这些事情很像创业，所以会产生强烈的进展感。

但它们都可以在没有一个客户的情况下完成。

如果目标是训练交易能力，本书把第一个关键里程碑定义为：

> **有没有一个非雇主的人，因为你创造的价值，自愿把钱付给你。**

这就是“第一笔新钱”。

## 为什么第一笔钱比第一家公司重要

在多数受雇岗位里，组织已经替你承担了交易链条中的许多环节，例如获客、岗位定义、协作组织、品牌和收款。你通常只需要重点完成其中一段工作。

当你独立赚钱时，其中很多环节需要自己面对。你会开始更完整地经历：

~~~text
找人
→ 理解问题
→ 提方案
→ 建立信任
→ 报价
→ 被拒绝
→ 成交
→ 交付
→ 收钱
~~~

哪怕最后只赚 300 元，这条链路对训练完整交易闭环，往往也比长期只做产品、不接触真实付费更直接。

## 第一笔钱应该怎么选

你的目标不是利润最大化。

而是：

> **尽快完成一次真实闭环。**

所以第一笔交易最好满足：

- 问题具体；
- 客户可接触；
- 你已经有一定能力；
- 交付周期短；
- 风险可控；
- 能明确验收。

不要从“我要创造一个伟大产品”开始。

可以从：

> 我能不能帮一个具体的人，把一个具体问题解决掉？

开始。

## 服务为什么适合小白练习

软件和内容可以规模化，但早期很容易躲在产品背后，长期不和客户接触。

服务的好处是逼迫你：

- 找客户；
- 听需求；
- 报价；
- 交付；
- 处理变化。

它不一定是你的最终商业模式，但通常很适合用来学习交易。

## 不要免费太久

免费可以用来换：

- 真实反馈；
- 案例；
- 数据；
- 进入场景的机会。

但如果始终只做免费测试，你就无法直接验证：

> **别人到底愿不愿意为它付钱。**

“觉得不错”和“愿意付款”是两个完全不同的信号。

写下一项你在 7～14 天内能够交付的具体服务。

必须回答：

1. 卖给谁？
2. 解决什么问题？
3. 做完有什么结果？
4. 你准备收多少钱？
5. 去哪里找到第一个人？
6. 最迟哪一天提出第一次真实报价？

不要写“准备好了再开始”。

交易能力只能在交易里学。
