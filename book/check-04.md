# 师傅检查四：你有没有真的走进交易现场

这一阶段不能只靠看书过关。

看真实动作。

## 你至少应该做过

- 主动联系过真实的人；
- 写过一份小方案；
- 说过一次真实价格；
- 记录过一次“不回 / 太贵 / 不需要”；
- 做过一张交付清单。

最好还有：

- 一笔真实成交。

如果没有成交，也不用硬凑。

只要能明确说出自己卡在：

> 找人 / 问题 / 信任 / 方案 / 价格 / 交付

哪一环，就有继续练的方向。

## 过关标准

你不再把这些词当成抽象概念：

> 客户、报价、拒绝、交付。

你已经碰过它们。

下一阶段不急着找更多客户。

先把已经发生过的交易拆开，看哪些能力和方法能够留下来。
