# 第三十一章：建立自己的机会数据库

当你持续做赚钱雷达、每日观察、每周研究和每月实验后，会产生大量信息。

如果这些东西散落在：

- 收藏夹；
- 微信；
- 浏览器标签；
- 脑子；
- 零散笔记；

你很难形成长期判断优势。

所以最后要建立一个：

> **机会数据库。**

它不是“待做项目列表”。

它是你长期观察现实后形成的私人地图。

## 一条机会应该记录什么

建议至少包含这些字段：

| 字段 | 含义 |
|---|---|
| 人群 | 谁遇到问题 |
| 场景 | 什么时候发生 |
| 问题 | 具体摩擦 |
| 频率 | 多久发生 |
| 损失 | 钱、时间、风险 |
| 当前方案 | 现在怎么解决 |
| 付款者 | 谁有预算 |
| 变化 | 为什么现在值得看 |
| 证据等级 | E0～E4 |
| 我的优势 | 为什么可能由我切入 |
| 下一步 | 最小验证 |
| 状态 | 观察 / 验证 / 放弃 / 进行中 |

## 数据库的价值来自“时间”

今天的一条观察可能没意义。

半年后，当你看到十几条记录都指向同一个问题时，它就变得很有意思。

例如半年内你持续记录：

- 餐饮老板抱怨平台流量贵；
- 私域运营需要大量人工；
- 顾客咨询高度重复；
- 店员培训流动率高；
- AI 工具成本不断下降。

单条信息不一定是机会。

当多条趋势叠加，你可能开始看到一个结构性变化。

这就是长期积累的优势。

## 记录“放弃原因”

机会数据库最容易只留下成功和兴奋。

但真正有价值的是保存：

> 为什么当时放弃？

例如：

- 用户痛但没预算；
- 获客成本太高；
- 平台限制；
- 技术还不成熟；
- 自己没有渠道。

半年后条件变化时，你可以重新检查。

放弃不是删除。

放弃也是数据。

## 定期做机会回顾

每个月花一小时：

1. 哪些问题重复出现？
2. 哪些证据等级提高了？
3. 哪些假设被证伪？
4. 哪些外部条件发生变化？
5. 哪三个问题最值得下个月验证？

你会逐渐从“今天什么火就看什么”，变成拥有自己的研究方向。

## 最终，你在积累什么

表面上是问题。

实际上你在积累：

- 行业理解；
- 用户语言；
- 价格感觉；
- 交易经验；
- 失败模式；
- 机会判断。

这些东西组合起来，就是你的商业认知资产。
