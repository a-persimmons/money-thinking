# 搞钱思维

> **没人教你，就从这里学。一步一步，练出自己的赚钱能力。**

这是一本面向没有商业启蒙、缺少家庭资源和“贵人”带路，但愿意踏实向上走的普通人的训练书。

它不提供“最赚钱的副业项目清单”，而是带读者从 0 走一条完整路径：

```text
看懂钱
→ 发现问题
→ 找到自己能卖的东西
→ 找人聊需求
→ 第一次报价
→ 被拒
→ 完成第一笔独立交易
→ 复盘与标准化
→ 自己发现机会
→ 建立第二收入和经济选择权
```

全书使用虚构人物“阿成”作为贯穿训练案例。案例中的人物、金额和情节用于教学，不声称是真实商业案例或行业统计。


```bash
npm run docs:build
```

推送到 `main` 后，GitHub Actions 会自动构建并部署 GitHub Pages。

## 全书结构

1. 先学会看钱
2. 学会发现值得解决的问题
3. 找到你能卖的第一样东西
4. 跑通第一笔独立交易
5. 从赚到一次，到长出能力
6. 学会自己找机会
7. 给自己多一条经济出路

中间穿插 5 次“师傅检查”，不让读者只读概念、不做练习。
