# 搞钱思维

> 从看不见钱，到看懂价值、交易与机会。

这是一本面向商业小白的开放式电子书。它不以“副业项目推荐”为主，而是训练一套可以长期迁移的赚钱认知：价值、问题、需求、付费者、交易、判断、下注、复制和系统。

## 本地阅读

~~~bash
npm install
npm run docs:dev
~~~

## 构建

~~~bash
npm run docs:build
~~~

## 在线部署

仓库已配置 GitHub Actions。推送到 `main` 后会自动构建 VitePress 并部署到 GitHub Pages。

项目站点预期地址：

`https://a-persimmons.github.io/money-thinking/`

## 结构

- 序章：为什么你缺的不是赚钱方法
- 第一部：先看懂——钱为什么流动
- 第二部：学会看——发现别人看不见的问题
- 第三部：学会判断——这个问题值不值得做
- 第四部：学会交易——从有价值到愿意付钱
- 第五部：第一次真正赚到“新钱”
- 第六部：从赚钱一次到拥有赚钱能力
- 第七部：发现机会并下注
- 第八部：让赚钱不再完全依赖时间
- 第九部：建立自己的赚钱操作系统
